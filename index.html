If it's free, you are the product.
Not here.

Wenn es nichts kostet, bist du das Produkt.
Hier nicht.

Most chat apps cost nothing because you pay with your data: who you talk to, when, how often and for how long. We are not up for that. RustTalk has no business built on your data and nothing to sell. The code is open, the server belongs to you, and your conversations never leave it. Owning your data again should not be a project for experts. It should be normal.

Die meisten Chat-Apps kosten nichts, weil du mit deinen Daten bezahlst: mit wem du sprichst, wann, wie oft und wie lange. Darauf haben wir keine Lust. Hinter RustTalk steckt kein Geschäft mit deinen Daten und nichts, das verkauft wird. Der Code ist offen, der Server gehört dir, und deine Gespräche verlassen ihn nicht. Die eigenen Daten wieder selbst zu besitzen sollte kein Projekt für Experten sein, sondern selbstverständlich.

End-to-end encrypted

Ende-zu-Ende-verschlüsselt

Messages, files, voice and video are encrypted on your device. The server only stores and forwards ciphertext, and even channel, role and profile names are encrypted. It does see who is a member, IP addresses and timing.

Nachrichten, Dateien, Sprache und Video werden auf deinem Gerät verschlüsselt. Der Server speichert und verteilt nur verschlüsselte Daten, sogar Kanal-, Rollen- und Profilnamen sind verschlüsselt. Er sieht aber, wer Mitglied ist, IP-Adressen und Zeitpunkte.

🔑

No account, no email

Kein Account, keine E‑Mail

Your identity is a 24-word recovery phrase on your device. No email, no phone number. Settings and servers sync between your devices.

Deine Identität ist eine Wiederherstellungsphrase aus 24 Wörtern auf deinem Gerät. Keine E-Mail, keine Telefonnummer. Einstellungen und Server werden zwischen deinen Geräten synchronisiert.

Roles & moderation

Rollen & Moderation

Roles with permissions, kick and ban, audit log. Removed people lose access to new messages, because the keys change.

Rollen mit Rechten, Kicken und Bannen, Audit-Log. Wer entfernt wird, kann neue Nachrichten nicht mehr lesen, weil die Schlüssel wechseln.

File sharing

Dateien teilen

Share files in chat, calls and DMs, end-to-end encrypted. Store them encrypted on your server, with size limits and expiry, or send them directly to the people in the conversation, never stored on the server.

Dateien in Chat, Anrufen und Direktnachrichten teilen, Ende-zu-Ende-verschlüsselt. Entweder verschlüsselt auf deinem Server gespeichert, mit Größenlimits und Ablaufzeit, oder direkt an die Leute im Gespräch geschickt, ohne Speicherung auf dem Server.

Host your own server

Eigenen Server hosten

A small Linux VPS is enough for a group of friends. Setup is a handful of commands.

Ein kleiner Linux-VPS reicht für einen Freundeskreis. Die Einrichtung sind nur ein paar Befehle.

What you need

Was du brauchst

A Linux server with Docker and a public IPv4 address. Open ports 443/tcp, 7881/tcp and 7882/udp, and 80/tcp if you use a domain. A domain name pointing at the server is optional: it gets a normal certificate. Without one, the server makes its own certificate and the invite link tells the app to trust it.

Ein Linux-Server mit Docker und einer öffentlichen IPv4-Adresse. Öffne die Ports 443/tcp, 7881/tcp und 7882/udp, mit Domain zusätzlich 80/tcp. Eine Domain, die auf den Server zeigt, ist optional: Damit gibt es ein normales Zertifikat. Ohne Domain erstellt der Server ein eigenes Zertifikat, und der Einladungslink sagt der App, dass sie ihm vertrauen kann.

Get the files

Dateien holen

git clone https://github.com/rusttalkcrew/rusttalk-next.git
cd rusttalk-next/deploy

Configure

Einstellen

Copy the example settings, then edit .env: set RUSTTALK_IP to the server's public IP address and LIVEKIT_API_SECRET to a random secret from openssl rand -hex 32. With a domain, also set RUSTTALK_DOMAIN.

Beispiel-Einstellungen kopieren, dann .env bearbeiten: RUSTTALK_IP auf die öffentliche IP-Adresse des Servers setzen und LIVEKIT_API_SECRET auf ein zufälliges Geheimnis aus openssl rand -hex 32. Mit Domain zusätzlich RUSTTALK_DOMAIN setzen.

cp .env.example .env
openssl rand -hex 32

Start

Starten

docker compose pull && docker compose up -d --wait

Claim your server

Server übernehmen

Print your owner invite and open it in the RustTalk app. Keep it private: whoever uses it first owns the server. Use the last line that fits your setup and fill in your IP address or domain.

Gib deine Besitzer-Einladung aus und öffne sie in der RustTalk-App. Halte sie geheim: Wer sie zuerst benutzt, besitzt den Server. Nimm die letzte Zeile, die zu deinem Setup passt, und trage deine IP-Adresse oder Domain ein.

code=$(docker compose exec -T api rusttalk-api owner-invite)
id=$(docker compose exec -T api rusttalk-api server-id)
pin=$(docker compose logs --no-log-prefix cert | sed -n 's/^TLS pin: //p' | tail -1)
echo "rusttalk://<ip>/i/$code#$id.$pin"   # IP-only mode
echo "rusttalk://<domain>/i/$code#$id"    # domain mode
