RustTalk ist kostenloser, verschlüsselter Voice-, Video- und Text-Chat, den du selbst betreibst. Keine Accounts, keine Werbung, kein Tracking. Nachrichten und Anrufe sind Ende-zu-Ende-verschlüsselt, selbst der Server kann nicht mitlesen.

Frühe Entwicklung. RustTalk ändert sich jeden Tag. Rechne mit Fehlern und mit Updates, die ältere Apps installieren müssen, bevor sie sich wieder verbinden können. Die Verschlüsselung wurde noch nicht unabhängig geprüft. Nutze es mit Freunden und verlass dich nicht darauf, wo ein Fehler wirklich schaden würde.

Wenn es nichts kostet, bist du das Produkt.
Hier nicht.

Die meisten Chat-Apps kosten nichts, weil du mit deinen Daten bezahlst: mit wem du sprichst, wann, wie oft und wie lange. Darauf haben wir keine Lust. Hinter RustTalk steckt kein Geschäft mit deinen Daten und nichts, das verkauft wird. Der Code ist offen, der Server gehört dir, und was du schreibst oder sagst, wird schon auf deinem Gerät verschlüsselt. Die eigenen Daten wieder selbst zu besitzen sollte kein Projekt für Experten sein, sondern selbstverständlich.

Dein Server, deine Regeln Du entscheidest, wer reinkommt, was gespeichert wird und wie lange.
Nichts zu verkaufen Keine Werbung, keine Analyse, keine Profile. Es gibt niemanden, an den deine Daten gehen.
Offen, nichts versteckt Jede Zeile Code ist öffentlich. Jeder kann nachprüfen, was RustTalk tut.

Alles, was eine Gruppe braucht

Eine native Desktop-App in Rust und ein Server, den du selbst mit Docker betreibst.

Klare Sprache

Opus-Audio mit Rausch- und Echounterdrückung und automatischer Lautstärke. Push-to-Talk oder Sprachaktivierung.

Bildschirm & Kamera

Bildschirm oder ein Fenster teilen, mit dem Ton der Apps deiner Wahl. Kamera gleichzeitig.

Kanäle & DMs

Textkanäle und Direktnachrichten, mit Verlauf, Antworten und Bearbeiten.

Ende-zu-Ende verschlüsselt

Nachrichten, Dateien, Anrufe und sogar Namen. Der Server sieht nur Chiffretext, dazu Mitglieder, IP-Adressen und Zeitpunkte.

Kein Account

Deine Identität ist eine Phrase aus 24 Wörtern. Keine E-Mail, keine Telefonnummer. Synchron auf all deinen Geräten.

Rollen & Moderation

Rollen, Kicken, Bannen und Audit-Log. Wer entfernt wird, liest keine neuen Nachrichten mehr: Die Schlüssel wechseln.

Dateien teilen

In Chats, Anrufen und DMs. Verschlüsselt gespeichert mit Limits und Ablaufzeit, oder live gesendet und nie gespeichert.

Signierte Updates

Die App installiert signierte Updates mit einem Klick. Der Server holt einfach neue Docker-Images.

Eigenen Server hosten

Ein kleiner Linux-VPS reicht für einen Freundeskreis. Die Einrichtung sind nur ein paar Befehle.

Was du brauchst

Ein Linux-Server mit Docker und einer öffentlichen IPv4-Adresse. Öffne die Ports 443/tcp, 7881/tcp und 7882/udp, mit Domain zusätzlich 80/tcp. Eine Domain, die auf den Server zeigt, ist optional: Damit gibt es ein normales Zertifikat. Ohne Domain erstellt der Server ein eigenes Zertifikat, und der Einladungslink sagt der App, dass sie ihm vertrauen kann.

Zuhause hosten? Viele Anschlüsse (DS-Lite oder CGNAT, in Deutschland oft bei Kabel und Glasfaser) haben keine öffentliche IPv4-Adresse. Dann hilft auch keine Portfreigabe. Frag deinen Anbieter nach einer öffentlichen IPv4-Adresse oder nimm einen kleinen VPS.

Dateien holen

git clone https://github.com/rusttalkcrew/rusttalk-next.git
cd rusttalk-next/deploy

Einstellen

Beispiel-Einstellungen kopieren, dann .env bearbeiten: RUSTTALK_IP auf die öffentliche IP-Adresse des Servers setzen und LIVEKIT_API_SECRET auf ein zufälliges Geheimnis aus openssl rand -hex 32. Mit Domain zusätzlich RUSTTALK_DOMAIN setzen.

cp .env.example .env
openssl rand -hex 32

Starten

docker compose pull && docker compose up -d --wait

Server übernehmen

Gib deine Besitzer-Einladung aus und öffne sie in der RustTalk-App. Halte sie geheim: Wer sie zuerst benutzt, besitzt den Server. Nimm die letzte Zeile, die zu deinem Setup passt, und trage deine IP-Adresse oder Domain ein.

code=$(docker compose exec -T api rusttalk-api owner-invite)
id=$(docker compose exec -T api rusttalk-api server-id)
pin=$(docker compose logs --no-log-prefix cert | sed -n 's/^TLS pin: //p' | tail -1)
echo "rusttalk://<ip>/i/$code#$id.$pin"   # IP-only mode
echo "rusttalk://<domain>/i/$code#$id"    # domain mode

Später aktualisieren

Vorher ein Backup machen (siehe ausführliche Anleitung). RUSTTALK_VERSION in .env auf die neue Version setzen, das passende Release auschecken und dann:

docker compose pull && docker compose up -d --wait

Läuft schon Caddy, nginx oder Traefik auf Port 443? Hinter eigenem Reverse Proxy betreiben.
